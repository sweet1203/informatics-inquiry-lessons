🅰️ 데이터 분석 — 스프레드시트 기초

구글 스프레드시트에 내려받은 파일을 올리고 네 가지만 해 봅니다.

기능어떻게왜 필요한가
정렬데이터 → 시트 정렬큰 값·작은 값 찾기
필터데이터 → 필터 만들기일부만 골라 보기
=AVERAGE(범위)평균거의 모든 연구에 필요
=COUNTIF(범위,조건)조건에 맞는 개수계수 문제에 필요
💡 오늘의 성공 기준 — 내 데이터에서 평균 하나를 내 본다.

🅱️ 피지컬 컴퓨팅 — 아두이노 켜기

교과서 148~149쪽 절차 그대로입니다. 센서는 아직 안 꽂습니다.

순서할 일확인
1아두이노 IDE 실행 → 보드: Arduino Uno
2도구 → 포트에서 나타난 것 선택안 보이면 USB 케이블 교체
3파일 → 예제 → 01.Basics → Blink
4업로드(→ 버튼)보드 LED가 1초마다 깜빡임
⚠️ 여기까지 안 되면 센서를 꽂지 마세요. 보드부터 살려야 합니다.
포트가 안 보이는 게 가장 흔한 문제이고, 대부분 USB 케이블 탓입니다. 충전 전용 케이블은 데이터가 안 통합니다.
💡 오늘의 성공 기준 — LED가 깜빡인다.

🅲 프로그램 제작 — 티처블 머신 첫 모델

순서할 일
1teachablemachine.withgoogle.com → 이미지 프로젝트
2클래스 2개만 만들기 (예: 캔 / 페트병)
