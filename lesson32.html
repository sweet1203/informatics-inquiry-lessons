🅰️ 데이터 분석 — KOSIS에서 실제로 받기

교과서 118~121쪽의 절차입니다. 클릭 순서까지 그대로 따라 하면 됩니다.

순서할 일
1kosis.kr → 국내 통계 → 주제별 통계
2원하는 분야 선택 (인구 · 교통 · 환경 …)
3항목 탭에서 필요한 값만 고르기
4시점 탭에서 연도·월 범위 정하기
5행에 지역·항목, 열에 시점이 왔는지 확인
6내려받기 → 스프레드시트로 열기
💡 오렌지3를 쓴다면 — File → Data Table로 불러온 뒤 Scatter Plot이나 Distributions를 연결해 보세요. 클릭만으로 그래프가 나옵니다.
✅ 성공 기준 — 내 주제에 쓸 표가 화면에 열려 있고, 몇 줄인지 안다.

🅱️ 피지컬 컴퓨팅 — 센서 값 읽기

교과서 158~159쪽 절차입니다. 이제 센서를 꽂습니다.

순서할 일주의
1USB를 뽑고 배선전원 켜진 채 꽂으면 센서가 탈 수 있음
2배선도대로 연결빨강 5V · 검정 GND
3라이브러리 설치 (필요한 센서만)DHT11은 DHT sensor library
4예제 스케치 업로드
5시리얼 모니터 열기 → 속도 9600글자가 깨지면 속도 확인
⚠️ 조도 센서(CDS)는 10kΩ 저항이 반드시 필요합니다. 없으면 계속 1023만 나옵니다.
저항 색띠 — 갈색-검정-주황
✅ 성공 기준 — 시리얼 모니터에 값이 계속 찍힌다. 손으로 센서를 가리거나 입김을 불면 값이 변한다.

🅲 프로그램 제작 — 모델 개선

앞 시간 모델을 그대로 두고 조건을 바꿔 가며 정확도를 봅니다.

바꿔 볼 것확인할 것
사진을 20장 → 40장으로정확도가 오르나?
배경을 바꿔서 찍기배경이 달라도 맞히나?
각도를 다양하게비스듬해도 맞히나?
클래스를 3개로 늘리기어느 클래스가 가장 못 맞히나?
💡 바꿀 때는 하나씩. 두 개를 한꺼번에 바꾸면 무엇 때문에 좋아졌는지 알 수 없습니다. 이게 앞에서 배운 조작 변인입니다.
✅ 성공 기준 — 조건을 바꿔 본 결과를 표로 적었다.
