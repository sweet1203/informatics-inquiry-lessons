1. 추상화 다섯 단계를 순서대로 놓은 것은?
  1. ① 자료 수집 → 자료 표현 → 자료 분석 → 문제 분해 → 문제 재구성
  2. ② 자료 수집 → 자료 분석 → 자료 표현 → 문제 분해 → 문제 재구성
  3. ③ 문제 분해 → 자료 수집 → 자료 분석 → 자료 표현 → 문제 재구성
  4. ④ 자료 분석 → 자료 수집 → 문제 재구성 → 자료 표현 → 문제 분해
  5. ⑤ 자료 표현 → 자료 수집 → 자료 분석 → 문제 재구성 → 문제 분해
답 보기

② — 모아서(수집) 살펴보고(분석) 정리한 뒤(표현), 쪼개고(분해) 핵심만 남깁니다(재구성). 수집 → 분석 → 표현이 자료를 다루는 앞쪽 셋, 분해 → 재구성이 문제를 다루는 뒤쪽 둘입니다.

2. 「우리 학교 통학 시간이 가장 긴 지역은 어디인가」는 어느 유형인가?
  1. ① 연산
  2. ② 결정
  3. ③ 최적화
  4. ④ 계수
  5. ⑤ 어느 유형도 아니다
답 보기

③ 최적화 — 「가장 ~인」을 묻고 있습니다. 여럿을 비교해 하나를 고르는 물음이에요.
「평균 통학 시간은 몇 분인가」였다면 연산, 「30분을 넘는 학생이 있는가」였다면 결정, 「통학 수단은 몇 가지인가」였다면 계수입니다.

3. 「교실이 답답하다」를 연구할 수 있는 형태로 가장 잘 바꾼 것은?
  1. ① 교실이 답답한 이유에 대한 학생들의 생각
  2. ② 교시별 이산화탄소 농도(ppm)
  3. ③ 교실 환경 개선 방안
  4. ④ 답답함을 느끼는 학생의 비율에 대한 고찰
  5. ⑤ 쾌적한 교실을 만드는 방법
답 보기

② — 숫자로 잴 수 있는 것으로 바뀌었습니다. 단위(ppm)까지 붙어 있어요.
①④는 「생각」·「고찰」이라 무엇을 잴지 여전히 불분명하고, ③⑤는 방법·방안이라 연구 질문이 아니라 목표입니다.

4. 컴퓨팅 사고력에서 사람이 맡는 쪽으로만 묶인 것은?
  1. ① 문제 분해 · 문제 재구성
  2. ② 반복 계산 · 병렬 처리
  3. ③ 시뮬레이션 실행 · 자료 저장
  4. ④ 문제 분해 · 반복 계산
  5. ⑤ 병렬 처리 · 문제 재구성
답 보기

① — 분해와 재구성은 추상화, 곧 사람의 일입니다. 반복 계산 · 병렬 처리 · 시뮬레이션 실행 · 자료 저장은 모두 자동화, 컴퓨터의 일이에요. ④⑤처럼 한쪽씩 섞은 보기가 함정입니다.

변인 — 무엇을 바꾸고 무엇을 고정하나

변인뜻예 — 교실 조도 연구

쓰는 곳보고서 ④ 결과보고서 ⑤ 결과 해석
⚠️ ④ 결과 칸에 「시끄러웠다」를 쓰면 감점입니다. 가장 흔한 실수예요. 「시끄러웠다」는 판단이라 ⑤에 들어갑니다.

답 보기

④ — 「~때문이다」는 판단이라 ⑤ 결과 해석에 들어갑니다. 게다가 원인을 단정하고 있어 ⑤에 넣더라도 「다만 ~도 겹쳐 있어 단정하기 어렵다」를 붙여야 합니다.

  2. ② 근거
  3. ③ 제안
  4. ④ 답과 근거
  5. ⑤ 빠진 것이 없다
답 보기

③ 제안 — 「2.4배였다」가 답, 「86명 대 36명」이 근거입니다. 「그래서 무엇을 하면 좋은가」가 없어요. 예를 들어 「시험 기간에는 열람실을 추가 개방하면 좋겠다」를 붙여야 세 겹이 찹니다.

  2. ② 도서관 이용자가 많아서 미세먼지가 높아졌다
  3. ③ 미세먼지와 도서관 이용자 수는 아무 관계가 없다

  5. ⑤ 미세먼지 농도로 도서관 이용자 수를 정확히 예측할 수 있다
답 보기

④ — 함께 나타났다는 사실만 말하고, 겹쳐 있는 다른 요인을 함께 적었습니다.
①②는 원인을 단정했고, ③은 관계가 보이는데 없다고 했으며, ⑤는 예측까지 넘어갔습니다. 이 유형은 「다만 ~」이 붙은 보기가 정답인 경우가 많습니다.

23점④ 한계와 개선 방향 · 데이터는 표다

12정연01-09 · 29차시 · 30차시 · 7문항 — 수업에서 다루지 못한 부분

🎯 한계를 쓰는 건 약점 고백이 아닙니다.
한계를 모르는 연구는 과장이 되고, 아는 연구는 정직해집니다.

한계는 셋 중 하나입니다

분류무슨 뜻예
자료 부족양이나 기간이 모자람사흘만, 2·3교시만 재서 하루 전체는 모름
자료 편중한쪽에 쏠림창가 한 곳에서만 재서 교실 뒤는 반영 안 됨
방법·도구의 제약그 방법으로는 알 수 없는 것센서가 dB이 아니라 0~1023 값을 줘서 절대 수치로 말 못 함
⭐ 한계마다 「개선 방향」을 하나씩 붙여야 제값을 받습니다. 「다시 한다면 ~하겠다」 형태면 충분해요.
❌ 이렇게 쓰면 한계로 인정되지 않습니다
「특별한 한계는 없었다」 · 「시간이 부족했다」 · 「내 실력이 부족했다」
일정 문제나 자책은 연구의 한계가 아닙니다. 자료와 방법을 말해야 합니다.

범주형종류를 나누는 것교시 · 요일 · 지역 · 품목세기 · 묶기 · 비교

  3. ③ 과제가 많아 측정할 시간이 부족했다
  4. ④ 한 학년만 조사해 전교생에게 적용하기 어렵다

① — 셋 다 종류를 나누는 값입니다.
③⑤는 전부 수치형, ②④는 섞여 있습니다. 「평균을 낼 수 있으면 수치형」이라고 생각하면 빠릅니다 — 요일의 평균은 뜻이 없지만 기온의 평균은 뜻이 있죠.

4. 컴퓨터로 분석하기 어려운 표를 만든 것은?

  2. ② 열 제목을 첫 줄에만 썼다
  3. ③ 요일마다 소계 줄을 넣고 맨 아래에 합계 줄을 넣었다
  4. ④ 단위를 열 제목에 적고 칸에는 숫자만 넣었다
